# 🏠 Home Assistant Blueprints by Egor Smirnov

Привет! Это коллекция моих автоматизаций для Умного Дома.
Все блупринты поддерживают **HACS** и стандартный импорт.

## 📥 Как установить

**Способ 1: HACS (Рекомендуемый)**
1. HACS > Integrations > Custom Repositories.
2. URL: `https://github.com/smirnowegor/HomeAssistant_blueprints`
3. Category: **Blueprint**.

**Способ 2: Кнопки ниже**
Просто нажмите на синюю кнопку "Import" под нужным блупринтом.
